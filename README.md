# 🎬 CINEVERSE – Movie Ticket Booking System

**A Console-Based Movie Ticket Booking Application Developed Using Python and Object-Oriented Programming (OOP).**

## 📌 About the Project

CINEVERSE is a Python-based Movie Ticket Booking System designed to simulate the real-world cinema ticket reservation process. It provides users with an interactive console interface to select movies, choose theatres, view show timings, book seats, order food, apply discount coupons, and complete payments.

The project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** concepts in Python while providing an understanding of real-world application development.

## ✨ Key Features

- 🔐 **User Login:** Collects and manages user information.
- 🎥 **Movie Selection:** Displays available movies for booking.
- 🏢 **Theatre Selection:** Allows users to select their preferred theatre.
- 🕒 **Show Timings:** Provides available show schedules.
- 💺 **Seat Booking:** Allows users to select seats and prevents duplicate bookings.
- 🍿 **Food Ordering:** Supports ordering snacks, popcorn, beverages, and other food items.
- 🎟️ **Coupon System:** Applies predefined discount coupon codes.
- 💳 **Automated Billing:** Calculates ticket prices, food costs, GST, and discounts.
- 🧾 **Booking Confirmation:** Generates booking details after payment.
- 📂 **Booking History:** Maintains previous booking records.
- ⚙️ **Admin Panel:** Provides seat reset and management functionality.
